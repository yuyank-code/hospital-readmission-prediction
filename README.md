# Hospital Readmission Prediction

A reproducible educational case study for predicting 30-day hospital readmission using Logistic Regression with L2 regularization.

## Model
- Logistic Regression (L2 regularization)
- ROC-AUC evaluation
- Threshold selection to illustrate the clinical trade-off between false negatives and false positives

## Dataset
The included training script generates a synthetic patient dataset shaped around the requested variables (vitals, diagnosis categories, prior visits, length of stay, etc.). It is intentionally synthetic and is **not clinically validated**.

## Results
The repository contains the trained model, metrics, ROC curve, and coefficient analysis generated by the training run.

## Run
```bash
pip install -r requirements.txt
python src/train.py
```

See `report/` for the case-study and learning report.
